# Security

## Reporting a problem

Please report it privately, not in a public issue, pull request or discussion.

Use GitHub's private vulnerability reporting: on this repository's page, open the **Security** tab and choose
**Report a vulnerability**. Only the maintainers can see the report.

## What's covered

- the uploader in this repository, on Windows, Linux and macOS, including its settings page, sign-in and what it
  sends;
- update signing: how updates are checked, the signing tools and scripts, and the release workflow;
- the files published in this repository's releases.

The dashboard it uploads to is a separate codebase, and isn't covered here.

Fixes go into new releases: please check the problem is still there in the newest one.

## What to expect

We aim to answer within 7 days to say we've got the report, and to say within 14 days whether we can reproduce it and
what we mean to do. We'll keep you posted until it's fixed, and credit you in the release notes if you'd like. Please
give us a chance to release a fix before telling others.
