Live game folders

Separate from the replay folders above. While a game is on, Heroes writes a rejoin save for the account you're playing on, so you can reconnect if you drop. That save says which hero everyone picked, and it's the only place the uploader can read picks from before the game ends.

Live game check

When a game is loading, the uploader reads who's in it and tells you (with a Windows notification) about anyone you've played with or against before.

Besides replays, the uploader sends: while Check games as they load is on, the lobby file of each loading game (with every player's battletag) and rejoin saves from the folders switched on under Live game folders; and while you're signed in, whether Heroes is open and since when (signing out stops that).
